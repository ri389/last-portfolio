# Portfolio de Daril Arale

Portfolio personnel présentant mon parcours de développeur web, mes compétences techniques et mes projets.

## Pages

- `index.html` : présentation, compétences, expériences et projets sélectionnés.
- `projets.html` : galerie des projets web.
- `cv.html` : CV détaillé.
- `contact.html` : formulaire et coordonnées.

## Technologies

- HTML5 et CSS3
- JavaScript
- React
- Laravel
- Font Awesome

## Projets web

Les applications présentées incluent Media Downloader (Node.js, PostgreSQL, yt-dlp et Docker), ainsi que les projets du dossier `Projets/` : calculatrice, générateur de mots de passe, application de notes, quiz, générateur de citations, liste de tâches et site e-commerce.

## Lancer le portfolio

Ouvrir `index.html` dans un navigateur ou démarrer un serveur local depuis la racine du dépôt :

```bash
python -m http.server 8000
```

Puis ouvrir `http://localhost:8000`.
