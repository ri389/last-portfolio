## 🚀 Installation et Utilisation

1. **Cloner le repository**
   ```bash
   git clone [url-du-repo]
   cd Portfolio
   ```

2. **Ouvrir le site**
   - Ouvrir `index.html` dans un navigateur web
   - Ou utiliser un serveur local pour un meilleur rendu

3. **Personnalisation**
   - Modifier les informations dans les fichiers HTML
   - Ajuster les couleurs dans `style.css` (variables CSS)
   - Ajouter vos propres projets dans les dossiers appropriés

## 🎨 Personnalisation

### Couleurs
Les couleurs sont définies dans les variables CSS :
```css
:root {
    --primary-color: #6366f1;
    --secondary-color: #8b5cf6;
    --accent-color: #06b6d4;
    /* ... autres variables */
}
```

### Contenu
- Modifier les textes dans les fichiers HTML
- Remplacer les images par vos propres créations
- Ajouter vos informations de contact
- Mettre à jour les liens vers vos réseaux sociaux
